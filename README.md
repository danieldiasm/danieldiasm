### ▲ Professional Hub Web Application (Svelte + Vite)

This repository also hosts my **Deus Ex: Human Revolution (Sarif Cyber-Renaissance)** themed professional hub built in **Svelte**.

#### Quick Start (Local Development)

```bash
cd danieldiasm
npm install
npm run dev
```

#### Production Build

```bash
npm run build
npm run preview
```

#### Customizing Content

- **Add / Edit Project Pages:** Edit [`src/data/projects.js`](./src/data/projects.js) (or use the interactive **`+ NEW PROJECT NODE`** builder directly on the web page to generate the config object).
- **Update Bio, Skills & Timeline:** Edit [`src/data/profile.js`](./src/data/profile.js).
- **Update Resume PDF:** Replace `public/resume/Daniel_03Nov26_EU-Version.pdf` (and update `resumePath` in `src/data/profile.js` if the filename changes).
